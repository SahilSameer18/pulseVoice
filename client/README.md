# PulseVoice Client (React Frontend)

The React frontend for **PulseVoice**, styled in the **Clinical Dusk** visual identity theme.

## 🚀 Running the Client

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Google Fonts (`Spectral`, `IBM Plex Sans`, `IBM Plex Mono`)
- **Transport**: `socket.io-client`
- **Audio Capture**: Browser `MediaRecorder` API
- **Text-to-Speech**: Browser `window.speechSynthesis` (Web Speech API)
